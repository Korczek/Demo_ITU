# Pathfinding Algorithm with Dynamic Grid Updates  

This project implements a **pathfinding algorithm** that reacts to **real-time changes on a grid**.  
It was originally created as part of a recruitment task, but it can be useful as a standalone reference for dynamic pathfinding.  

---

## ✨ Features  
- Grid-based map representation (configurable size).  
- Pathfinding using **A\***.  
- **Dynamic updates** → when obstacles or walkable tiles change, the algorithm automatically recalculates the path.  
- Efficient handling of grid modifications without recalculating from scratch.  
- Clear and modular codebase for easy extension.  

---

## 🛠️ Technologies  
- **Language:** C#  
- **Framework:** Unity
